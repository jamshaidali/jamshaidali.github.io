# jamshaid.info

Personal portfolio of **Jamshaid Ali**, Senior Software Engineer (Python backends & AI agents).

Live at **https://jamshaid.info**, served by GitHub Pages.

## Structure

- `index.html`: the whole site (HTML, CSS and a little JavaScript, no build step)
- `assets/og.png`: link preview image for LinkedIn and other sites (1200 × 627)
- `assets/favicon.svg`: browser tab icon
- `assets/Jamshaid_Ali_CV.pdf`: downloadable CV
- `CNAME`: custom domain for GitHub Pages

## Updating

Edit `index.html` and push to `main`. GitHub Pages redeploys in about a minute.
To update the CV, replace `assets/Jamshaid_Ali_CV.pdf` with a file of the same name.
