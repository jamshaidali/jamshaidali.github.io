Problems I've debugged

Short write-ups from real systems. Full posts are on LinkedIn.

CDC · Kafka · Debezium

Migrating a database without breaking the event stream

Rebuilt the PostgreSQL → CDC → Kafka pipeline in isolation, found a replication-slot misconfiguration, migrated with AWS DMS and recreated the slots on the new database.

No data loss · no broken pipelines Gunicorn · Grafana · Django

Why a sync endpoint kept killing workers

Traced timeouts to a new auth token on every call and a materialized view refreshing over and over. Cached the token and refreshed the view once per sync.

Worker timeouts → none Python 3.14 · concurrency

Subinterpreters vs processes for CPU-bound work

Benchmarked InterpreterPoolExecutor against threads and processes: process-like parallel speed with about half the startup cost.

50 tiny tasks: 0.271 s → 0.128 s
